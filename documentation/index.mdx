## Goal

The framework provides a **foundational architecture** that makes it easy to build powerful and extendable Cloudflare Workers applications with a plugin system.

By offering essential building blocks with a clean and easy to use API, it eliminates boilerplate while enabling infinite extensibility.

## What's in the box?

By default, worker-plugins provides:

- **Type-safe RPC communication** routing (ala TRPC)
- **Type-safe WebSocket management** with automatic reconnection and presence tracking
- **Task scheduling** support within Durable Objects
- **Synchronous KV storage** inside Durable Objects
- **Type-safe queues**
- **Cron support**
- **Plugin architecture** for extending functionality
- **Type-safe client SDK** to interact with your Workers and Durable Objects in a type-safe way

## Architecture Overview

Worker-Plugins consists of three main layers:

1. **Worker Layer**: HTTP endpoints, queue and cron handlers.
2. **Durable Object Layer**: WebSocket connections, and task scheduling
3. **Client Layer**: Type-safe SDK for external applications

Each layer is designed to work seamlessly together while maintaining type safety and providing production-ready features.
