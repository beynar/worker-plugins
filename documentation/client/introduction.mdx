# Client SDK Introduction

The Worker-Plugins client SDK provides type-safe access to your APIs from external applications.

## Creating a Client

```typescript
import { createClient } from "worker-plugins/client";

const client = createClient<WorkerInfer>({
  endpoint: "https://my-worker.workers.dev",
});
```
