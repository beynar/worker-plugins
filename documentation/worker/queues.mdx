## Basic Queue Handler

```typescript
const worker = createWorker().queues((q) => ({
  email: q.procedure().handle(async ({ message }) => {
    await sendEmail(message.body);
  }),
}));
```

## Queue Configuration

Configure queues in your `wrangler.jsonc`:

```json
{
  "queues": {
    "producers": [
      {
        "queue": "email-queue",
        "binding": "EMAIL_QUEUE"
      }
    ],
    "consumers": [
      {
        "queue": "email-queue",
        "max_batch_size": 10,
        "max_retries": 3
      }
    ]
  }
}
```
