---
title: "Adding Durable Objects"
description: "For more complex applications, you can add Durable Objects to your Worker. Their routes are automatically routed to the correct Durable Object."
---

## Automatic Routing

```typescript
const worker = createWorker()
  .router((t) => ({
    users: {
      create: t.handle(async ({ event }) => {
        // Automatically routes to USERS Durable Object
        return await event.env.USERS.getByName("default").create({
          name: "John",
          email: "john@example.com",
        });
      }),
    },
  }))
  .object("USERS", UserService);
```
